## 배포 방식 (CD — 2026-08-19부터, `.github/workflows/deploy.yml`)

- **main 머지 = 자동 배포**: 기능 PR → develop 머지 → 배포하고 싶을 때 develop→main PR 머지 → Actions "Deploy"가 SSH로 `git reset --hard origin/main` → `docker compose up -d --build app` → `/health` 확인 (1~2분, 앱 10~20초 재시작). db 컨테이너·`.env`는 안 건드린다
- **금지 시간**: 발표 중, 발표 당일 06:00~09:00(배치 시간). 재기동되면 그날 06:00 생성이 중간에 끊긴다(멱등이라 다음 날 이어서 하지만 당일 카드가 덜 찬다)
- 안전장치: 컨테이너 안에서 `generate_now`/`collect_now`/`seed_knowledge`가 도는 중이면 배포가 **실패로 멈춘다**(죽이지 않음). 끝난 뒤 Actions → Deploy → Run workflow. 고아 프로세스면 `docker compose top app`으로 확인 후 `docker compose restart app`
- 긴 배치는 `nohup docker compose exec -T app python -m scripts.generate_now > gen.log 2>&1 &` — SSH 끊겨도 계속, `tail -f gen.log`로 진행 확인
- 시크릿(저장소 Settings → Secrets): `DEPLOY_HOST` / `DEPLOY_USER` / `DEPLOY_SSH_KEY`(pem 전체) — 서버 교체 시 이 세 개만 갱신
