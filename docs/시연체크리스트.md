## D-2 ~ D-1: 서버 준비 (8/18 가비아 확보 후)

- [ ] 서버에 Docker 설치, 저장소 clone, `.env` 작성 — **`ENABLE_SCHEDULER=true` 필수**(빠지면 06:00 배치가 안 돈다)
- [ ] `docker compose up -d` → `GET /health` 200 확인
- [ ] 1회성 시드(순서대로):
  ```bash
  docker compose exec app python -m scripts.sync_stock_master      # 국내 종목 마스터
  docker compose exec app python -m scripts.sync_corp_codes        # DART 매핑
  docker compose exec app python -m scripts.sync_overseas_master   # 해외 15종 + 업종·폼 해설
  docker compose exec app python -m scripts.seed_rate_decisions    # 금리 결정문
  docker compose exec app python -m scripts.seed_knowledge         # RAG 지식베이스 (약 10분)
  ```
- [ ] 프론트에 서버 IP 전달 → Vercel rewrite destination 갱신 (docs/프론트연동가이드.md)
- [ ] 프록시 경유 스모크: 프론트 도메인에서 `/api/health` 200

## D-1: 데이터·검수

- [ ] 시연 종목 등록(데모 세션에서 종목 추가) 후 전체 수집·생성:
  ```bash
  docker compose exec app python -m scripts.collect_now
  docker compose exec app python -m scripts.generate_now
  ```
- [ ] 시연 종목 카드 전수 검수(요약·라벨 눈으로 확인) → 잠금:

  (요약 미생성 항목이 있으면 스크립트가 먼저 알려준다 → generate_now 재실행)

- [ ] DB 백업: `docker compose exec db pg_dump -U assit assit > backup_$(date +%m%d).sql`

## D-0: 시연 직전

- [ ] `python -m scripts.collect_now` — 당일 자료 반영 (유튜브는 24h 캐시로 쿼터 보호)
- [ ] `python -m scripts.generate_now` — 신규 자료 요약 (잠긴 검수본은 안 덮인다)
- [ ] 데모 계정 초기화가 필요하면 `POST /admin/reset-demo` (X-Admin-Token 헤더)
- [ ] 발표용 지표 출력: `python -m scripts.report_metrics`
- [ ] 리허설 동선: 홈 → 종목 추가(로그인) → 탭 4종 → 용어 드래그 → 카드 저장 → 저장됨 → 구분 전환
