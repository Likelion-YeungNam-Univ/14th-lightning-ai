# 지불 의사 검증 플랜 (심사 배점 10점 대응)

팀 번개조 | 2026.08 | 실행 주체: PM (개발과 병렬 진행, 개발 일정에 영향 없음)

심사 문항: **"인터뷰, 시장조사 등 실제 고객 접점을 통해 '돈을 낼 이유'를 확인하거나 검증했는가"**

현재 상태: PRD의 인터뷰 4건은 '불편(pain)'을 검증했지 '지불(pay)'을 검증하지 않았다. 이 문서는 발표일 전까지 실행 가능한 검증 3트랙과, 발표 슬라이드에 올릴 증거 형태를 정의한다.

---

## 0. 전제: 과금 포인트 설계 (규제 주의)

**"판단·추천"에 과금하면 유사투자자문업 신고 대상이 될 수 있다.** assit은 애초에 매수·매도 판단을 하지 않는 제품이므로(PRD 1.2), 과금 포인트도 판단이 아니라 **편의**에 둔다. 이 논리는 심사 질의응답에서도 방어 논거가 된다 ("우리는 자문이 아니라 정리를 판다").

**가격 가설 (인터뷰로 조정할 초안):**

| 플랜 | 내용 | 가격 가설 |
| :---- | :---- | :---- |
| 무료 | 기본 종목 4개 + 다섯 탭 열람 | 0원 |
| 프리미엄 | 종목 무제한, 저장 무제한, **내 종목 데일리 브리핑 알림**(아침 1회 요약 푸시) | 월 2,900 ~ 4,900원 |

알림(브리핑)이 핵심 유료 후보인 이유: "아침에 뉴스 보고 내 종목이 걱정된다"(PRD 시나리오)는 순간을 서비스가 먼저 찾아가는 기능이라, 열람 편의보다 지불 명분이 강하다.

## 1트랙. 인터뷰 재접촉 + 신규 (목표 N=10, 이번 주 착수)

기존 인터뷰이 4명 재접촉 + 신규 6명(대학 커뮤니티·투자 단톡방 리크루팅). 15분 전화/대면. **아래 순서 그대로 진행** — 가격을 먼저 말하면 이후 답변이 오염된다.

### 질문 스크립트

**A. 기존 지출 파악 (가장 중요한 증거 — "이미 이 문제에 돈을 쓰고 있는가")**
1. 투자 정보를 얻으려고 돈을 써 본 적 있나요? (유료 리딩방, 뉴스레터 구독, 책, 강의, 증권사 유료 서비스, 유튜브 멤버십 등) 얼마였나요?
2. 무료로 쓰지만 시간을 많이 쓰는 채널은? 하루/주에 몇 분?

**B. 가치 확인 (프로토타입/목업 보여준 후)**
3. 이 화면이 있으면 지금 하는 탐색 중 무엇이 없어지나요?
4. 일주일에 몇 번 열어볼 것 같나요? 어떤 순간에?

**C. 지불 사다리**
5. 이 서비스가 유료라면, 무엇 때문에 돈을 낼 것 같나요? (자유 응답 — 유료 기능 후보 발굴)
6. "내 종목 아침 브리핑 알림"이 월 2,900원이면? → (반응 후) 4,900원이면? → 얼마부터 안 쓰나요?

**D. Van Westendorp 4문항 (정량 그래프용)**
7. 너무 싸서 품질이 의심되는 가격은?
8. 싸다고 느끼는 가격은?
9. 비싸지만 고려할 가격은?
10. 너무 비싸서 안 쓸 가격은?

### 산출물
- WTP(지불의사가격) 분포 그래프 1장 (N=10, Van Westendorp 교차점)
- "이미 지출 중" 응답자 비율 + 지출처·금액 인용문 2~3개

## 2트랙. 가짜 문(Fake Door) 랜딩 테스트 (3~5일 노출)

서비스 소개 1페이지를 만들어 CTA 두 개를 나란히 배치:

- `[무료로 시작 알림 받기]`
- `[프리미엄 사전등록 — 월 2,900원 (출시 시 50% 할인)]`

**측정: 방문 대비 각 CTA 클릭률, 그리고 프리미엄 클릭의 비중.** 클릭 후엔 "준비 중입니다 + 이메일 남기기"로 마무리 (실결제 유도 금지 — 플랫폼 정책·윤리 리스크 회피). 프리미엄 클릭 = 가격을 보고도 누른 지불 신호다.

- 배포 채널: 에브리타임/캠퍼스픽, 주식 초보 커뮤니티·오픈카톡, 팀 SNS
- 도구: 프론트 스택으로 1페이지 + `event_log` 방식 클릭 집계 (또는 Tally/waitlist 툴)
- 성공 기준 예시: 방문 100+ 확보, 프리미엄 CTA가 전체 클릭의 15% 이상이면 "가격 보고도 누른 사용자 존재"로 보고 가능

## 3트랙. 대체재 지출 데스크 리서치 (반나절)

"20대는 투자 정보에 돈을 안 쓴다"는 심사 반론에 대한 선제 방어. **이미 형성된 지불 시장**의 가격표를 정리한다:

- 유료 투자/경제 뉴스레터 구독료, 경제 유튜버 멤버십 가격, 증권사 유료 리서치/구독 상품, 유료 리딩방 시세(문제적 시장이지만 "지불 의사가 존재한다"는 역설적 증거)
- 프레임: "이 문제에 이미 월 X천~X만원이 지불되고 있고, 우리는 그중 '검증 가능한 공공 데이터 정리'라는 빈 자리를 더 낮은 가격에 가져간다"

---

## 발표 슬라이드 구성 (지불 의사 = 2장)

1. **"이미 돈을 쓰고 있다"** — 3트랙 가격표 + 1트랙 A의 실제 지출 인용
2. **"우리 제품에도 낸다"** — Van Westendorp 그래프(N=10) + 랜딩 프리미엄 CTA 전환율 + 수익모델(무료/프리미엄, 과금은 판단이 아닌 편의라는 규제 방어 논리 한 줄)

## 일정

| 일자 | 액션 |
| :---- | :---- |
| D+0~1 | 가격 가설 팀 합의, 인터뷰 스크립트 확정, 리크루팅 시작 |
| D+1~2 | 랜딩 1페이지 제작·배포 (개발팀 반나절 지원 — P2 이후 목업 화면 재사용) |
| D+2~6 | 인터뷰 10건 진행, 랜딩 노출 |
| D+6~7 | 집계 → 그래프 → 슬라이드 2장 |
