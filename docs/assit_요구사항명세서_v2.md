# F-1. 계정 · 세션

> 로그인은 첫 관문이 아니다. 비로그인으로 다섯 탭을 모두 열람하고, **종목 추가**와 **카드 저장** 두 지점에서만 로그인을 요구한다.  
>   
> **실제 인증은 구현하지 않는다.** 사전 설정한 계정 하나를 입력하면 로그인된 것으로 처리하는 시연용 모의 구현이다.  
>   
> **데이터는 계정이 아니라 세션에 귀속시킨다.** 계정이 하나뿐이라 계정에 데이터를 붙이면 시연 중 여러 사람이 서로의 종목을 보게 된다.

| 페이지 | 기능 | 질문 | 세부 사항 | 우선순위 |
| :---- | :---- | :---- | :---- | :---- |
| **\[F-1.1\] 세션 발급** | 사용자 상태 보관 | 세션 보관 기간 확정 필요 (제안: 30일) | 첫 진입 시 세션 식별자를 발급하고 쿠키에 저장한다. 이 세션에 기본 종목 4개를 프로비저닝한다(F-2.8). **등록 종목과 저장 카드는 로그인 여부와 무관하게 이 세션에 귀속된다** | 상 |
| **\[F-1.2\] 모의 로그인** | 사전 설정 계정으로 로그인 처리 | 시연용 계정 값 확정 필요 | 입력값이 사전 설정 계정과 일치하면 세션에 `authenticated = true`를 세운다. **계정 값은 저장소에 커밋하지 않고 환경 변수로 주입.** 가입·중복 확인·이메일 인증·비밀번호 재설정·로그아웃은 만들지 않는다 | 상 |
| \[F-1.3\] 로그인 요구 지점 | 종목 추가·카드 저장 시 인증 확인 |  | `authenticated`가 아니면 401\. **이 두 곳 외의 엔드포인트는 인증을 보지 않는다.** 로그인 창은 프론트 책임 | 상 |
| \[F-1.4\] 진행 중 행동 이어가기 | 로그인 후 원래 행동 완료 |  | 데이터가 세션에 그대로 있으므로 이관은 불필요하다. 프론트가 401 이전 요청을 재전송하면 된다. **백엔드에서 별도 상태 저장은 하지 않는다** | 상 |
| \[F-1.5\] 데모 데이터 초기화 | 시연 전 세션 상태 되돌리기 | 노출 방식(관리자 경로 / 스크립트) 확정 필요 | 세션의 종목·저장 카드를 지우고 기본 종목 4개로 되돌린다. **리허설을 반복하면 첫 진입 화면을 재현할 수 없으므로 반드시 필요하다** | 중 |

# F-3. 외부 데이터 수집

> 전 탭 **1일 1회 배치**. 종목을 새로 추가하면 그 종목만 즉시 1회 수집. **사용자 요청 경로에서 외부 API를 직접 부르지 않는다.**

| 페이지 | 기능 | 질문 | 세부 사항 | 우선순위 |
| :---- | :---- | :---- | :---- | :---- |
| **\[F-3.1\] 공시 수집 (DART)** | 종목별 최근 공시 적재 | 대상 공시 유형 범위 확정 필요 | `corp_code` 기준 공시검색. 적재: 접수번호, **공시 제목(원문 그대로)**, 공시 유형, 제출일, 원문 링크. 최근 3개월, 종목당 최신 20건. **원본파일 파싱은 범위 밖** | 상 |
| **\[F-3.2\] 규제 동향 수집** | 산업에 걸리는 부처 발표 적재 |  | 정책브리핑 API(등록번호 15095335\) → 부처 1차 필터 → 종목명·산업 키워드 2차 필터. 조회 기간 3개월. **이미지·사진·영상 URL은 저장·노출하지 않는다.** 텍스트는 공공누리 출처표시 준수 | 상 |
| \[F-3.2.1\] 부처 매핑표 적재 | 산업 → 소관 부처 | **부처 문자열 대조 필요.** 2025년 10월 개편(산업통상자원부→산업통상부, 환경부→기후에너지환경부)이 API 응답에 반영됐는지 착수 첫날 확인 | PRD 부록 C 초안을 적재. **코드가 아니라 데이터로 관리**(설정 파일 또는 DB). 매핑 없는 업종은 조회하지 않고 빈 상태 처리 | 상 |
| \[F-3.3\] 한국은행 (ECOS) | 기준금리와 결정 요지 | **B3. 통계표 코드 \+ 결정 요지 텍스트 확보 경로 확인 필요** | 적재: 기준금리 값, 기준일자, 직전 대비 변동(인상/인하/동결), 결정 제목, 결정 요지 텍스트. **요지 텍스트가 없으면 카드의 주요 내용이 빈다** | 상 |
| \[F-3.4\] 미국 Fed (FRED) | 연방기금금리와 최근 결정 | 시리즈 ID 확정 필요. **FOMC 일정은 FRED 미제공** | 적재: 금리 값, 기준일자, 변동 방향 | 중 |
| **\[F-3.5\] 유튜브 영상 수집** | 종목 관련 영상 (조회수순) | 검색 쿼리 구성 규칙과 결과 건수 확정 필요 | 조회수순 검색. 적재: 썸네일 URL, 영상 제목, 채널명, 조회수, 게시일, 링크. **검색 1회 100유닛 / 기본 일일 10,000유닛 → 하루 약 100회.** 검색 응답에 조회수가 없어 영상 조회 호출 1회 추가(50건 묶음, 1유닛). 캐시 TTL 제안 24시간 | 상 |
| \[F-3.5.1\] 쿼터 방어 | 한도 초과 시 중단 방지 |  | **소비량 자체 집계**(잔여량은 응답으로 오지 않는다). 80% 도달 시 신규 검색 중단, 403 시 직전 캐시 노출 | 상 |
| \[F-3.5.2\] 시연 캐시 워밍 | 발표용 종목 사전 적재 | 시연 종목 목록 확정 필요 | 발표 전 해당 종목의 캐시를 채운다. **당일 쿼터 소진은 발표 실패와 같다** | 상 |
| \[F-3.6\] 배치 스케줄러 | 일 1회 수집 실행 | 실행 시각 확정 필요 (제안: 06:00) | 다섯 탭 자료·종목 마스터 1일, 고유번호 매핑 주 1회. 종목 신규 추가 시 온디맨드 1회 | 상 |
| \[F-3.7\] 수집 실패 격리 | 외부 API 장애 대응 |  | 지수 백오프 재시도(제안 3회). **실패는 빈 목록이 아니라 별도 상태로 반환**해야 프론트가 "자료 없음"과 "불러오지 못함"을 구분한다 | 중 |
| \[F-3.8\] 원자료 보관 정책 | 저작권 준수 |  | 기사·공시 본문 전문은 저장소에 커밋하지 않는다. 원문 링크는 원 매체에서 새 탭으로. 정책브리핑 이미지는 저장하지 않는다 | 상 |

# F-4. AI 가공

| 페이지 | 기능 | 질문 | 세부 사항 | 우선순위 |
| :---- | :---- | :---- | :---- | :---- |
| **\[F-4.1\] 카드 요약 생성** | 원자료를 쉬운 말로 |  | 대상: 공시·규제·한국은행·Fed (**유튜브 제외 — 요약 없음**). 입력 범위가 탭마다 고정: 공시는 제목+공시 유형까지, 규제는 API 본문, 금리는 지표 값과 결정 요지. **다른 탭 자료, 특히 유튜브 내용을 입력에 섞지 않는다.** 자료 단위로 1회 생성 후 재사용 | 상 |
| **\[F-4.1.1\] 요약 2단 생성** | 목록용과 시트용 | **한 번에 두 필드를 생성할지, 전문만 만들고 목록용을 잘라 쓸지 확정 필요** | PRD상 목록에는 두세 줄, 시트에는 전문이 들어간다. (제안) **`summary_short`와 `summary_full`을 한 번의 호출로 함께 생성한다.** 전문을 글자 수로 자르면 문장 중간에서 끊겨 목록 카드가 미완성 문장이 된다 | 상 |
| **\[F-4.1.2\] 제목 미가공** | 원문 제목 보존 |  | **제목은 LLM 출력 대상이 아니다.** 원문 제목을 그대로 저장·반환한다. 요약 생성 시 입력으로는 쓰되 제목 필드를 생성하지 않는다. 원문 페이지에서 같은 제목을 찾을 수 있어야 사용자가 대조할 수 있다 | 상 |
| \[F-4.1.3\] 공시 요약 제약 | 없는 정보 생성 차단 |  | **제목에 없는 금액·수량·계약 상대방·조건을 생성하지 않는다.** 본문을 읽지 않는 구조에서 가장 큰 위험이다. 후처리에서 숫자 토큰이 원문 제목에 없으면 차단 (제안) | 상 |
| **\[F-4.2\] 영향 라벨 생성** | 긍정/중립/부정 \+ 판단 이유 | **B4. 오판 검증 절차 미정** | 부착: 공시·규제 동향. 미부착: 유튜브·한국은행·Fed. 규칙: 퍼센트 미표기 / **판단 이유 필수 동반** / 애매하면 중립 / 정렬·집계 기준으로 쓰지 않음 | 상 |
| \[F-4.2.1\] 생성 단위 | 조합 폭발 방지 |  | 공시 \= **자료 1건 × 종목 1개**. 규제 \= **자료 1건 × 업종 1개**. 규제 라벨은 업종 단위로 한 번 만들어 공유한다. 생성량이 종목 수가 아니라 업종 수로 고정된다 | 상 |
| \[F-4.2.2\] 라벨 오용 차단 | 매수 신호화 방지 |  | **응답 스키마에 라벨 카운트·비율 필드를 만들지 않는다.** 정렬 파라미터로 라벨 값을 받지 않는다 | 상 |
| **\[F-4.3\] "내 종목엔" 문장** | 금리 지표를 업종에 잇는 한두 줄 |  | 대상: 한국은행·Fed 탭만, **목록 위에 1회**(카드마다 아님). 입력: 업종·성격 \+ 금리 지표 \+ 최근 변동 방향. 금지: 방향 예측, 매수·매도 시사, 수치 단정. **조건을 만족하지 못하면 빈 값을 반환하고 카드만 노출한다** | 상 |
| \[F-4.3.1\] 종목명 미사용 검증 | 정밀도 오인 차단 |  | 문장은 업종 단위이므로 **종목명을 부르지 않는다.** 생성물에 종목명 문자열이 있으면 재생성하거나 비운다 | 상 |
| \[F-4.3.2\] 문장 캐싱 | 표현 흔들림 방지 |  | 캐시 키 **`업종 + 지표 스냅샷`**. 지표 갱신 시에만 무효화 | 상 |
| \[F-4.4\] 용어 풀이 | 드래그한 단어를 문맥 기준 설명 | 응답 속도 대책 미정 | **호출 지점은 요약 시트다**(좁은 카드 목록에서는 드래그가 사실상 불가능). 입력: 드래그 텍스트 \+ 해당 자료의 요약 본문. 출력: 한두 줄 정의. **정의까지만 하고 영향 판단은 하지 않는다.** 캐시 키 제안 `용어 + 탭`. 입력 길이 상한 (제안: 50자) | 중 |
| \[F-4.5\] 출력 가드레일 | 금지 표현 차단 |  | 생성물 전체 공통 후처리. 차단: 매수·매도 권유, 목표가·상승률 등 수치 단정, 미래 방향 예측. **위반 시 재생성 1회, 그래도 위반이면 필드를 비운다** | 상 |
| \[F-4.6\] 생성물 무효화 | 원자료 갱신 시 재생성 |  | 원자료가 바뀌면 딸린 생성물을 무효화. **저장된 카드의 스냅샷은 건드리지 않는다** | 중 |
| \[F-4.7\] 검수 잠금 | 시연 종목 생성물 고정 | 검수 대상 확정 필요 | 검수 완료 상태로 잠글 수 있어야 한다. 재생성으로 덮이면 검수가 무의미해진다 | 중 |

# F-5. 콘텐츠 조회

> **카드 목록과 요약 시트는 같은 데이터를 쓴다.** 목록 조회 시 시트에 필요한 필드까지 함께 내려보내고, 시트를 열 때 추가 호출을 하지 않는다 (제안). 탭당 자료 건수가 20건 내외라 페이로드 부담이 작고, 시트를 열 때마다 왕복이 생기면 체감이 느려진다.

| 페이지 | 기능 | 질문 | 세부 사항 | 우선순위 |
| :---- | :---- | :---- | :---- | :---- |
| **\[F-5.1\] 카드 목록 조회** | 탭 × 종목 조합의 카드 반환 | 페이지네이션 필요 여부 (제안: 20건) | 파라미터 `tab`, `stock_code`. **응답 스키마는 다섯 탭이 공통이며 없는 요소는 `null`로 둔다**(F-5.1.1). 비로그인도 호출 가능 — `is_saved`만 `false` 고정 | 상 |
| **\[F-5.1.1\] 공통 카드 스키마** | 탭별 분기 최소화 |  | 필드: `label`, `label_reason`, `title`(원문), `summary_short`, `summary_full`, `source_name`, `published_at`, `origin_url`, `is_saved`, `thumbnail_url`, `channel_name`, `view_count`, `indicator_value`. **탭별로 필드를 빼지 말고 `null`로 채운다** — 프론트가 하나의 카드 컴포넌트로 렌더링하고 요소를 켜고 끈다 | 상 |
| \[F-5.1.2\] 탭별 채워지는 필드 | 무엇이 `null`인가 |  | 유튜브: `label`·`label_reason`·`summary_*`가 `null`, `thumbnail_url`·`channel_name`·`view_count` 채움. 공시·규제: 라벨과 요약 채움, 유튜브 필드 `null`. 한국은행·Fed: `label`·`label_reason` `null`, `indicator_value` 채움 | 상 |
| \[F-5.1.3\] 정렬 규칙 | 카드 나열 순서 |  | 기본 최신순, 유튜브만 조회수순. **라벨을 정렬 기준으로 제공하지 않는다** — 정렬 파라미터가 라벨 값을 아예 받지 않음으로써 확증편향 증폭을 구조적으로 막는다 | 상 |
| \[F-5.2\] 금리 탭 연결 문장 | 목록 위 1회 노출 |  | 응답 최상단에 `link_sentence`(업종 단위). **문장이 비어 있어도 카드는 반환한다.** 지표 카드는 모든 종목 공통이므로 종목별로 다시 계산하지 않는다 | 상 |
| \[F-5.3\] 유튜브 목록 부가 정보 | 참고용 표시 근거 |  | 응답에 `disclaimer` 플래그를 포함해 프론트가 "참고용 · 개인 의견입니다"를 **스크롤해도 사라지지 않게 고정 노출**할 근거를 준다. 시트가 없으므로 카드 탭은 외부 이동 | 상 |
| \[F-5.4\] 빈 상태 응답 | 자료 없음과 오류 구분 |  | 빈 배열 \+ 사유 코드: `no_data` / `fetch_failed`. **규제 동향 탭은 갱신 빈도가 낮아 자주 비므로 이 구분이 실제로 자주 쓰인다** | 중 |
| \[F-5.5\] URL 상태 복원 | 탭·종목 조합 북마크 |  | **조회 API는 직전 조회 이력에 의존하지 않는다.** URL 파라미터만으로 화면이 복원되어야 하고 뒤로 가기가 동작해야 한다 | 중 |
