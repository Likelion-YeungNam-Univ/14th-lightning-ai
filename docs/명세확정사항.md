> **읽는 법** — 구현 기준은 **v3 명세 + 이 문서**다. 두 문서가 어긋나면 **이 문서가 우선**한다.

## 0. 검토 결론

**v3 명세는 기술적·정책적으로 전부 구현 가능하다.** 해외 축의 두 신규 소스는 오히려 국내보다 조건이 좋다 — SEC EDGAR·Federal Register 모두 **API 키 불필요·무료·퍼블릭 도메인**이다. 단 두 가지 조건을 확정한다:

1. **개발 순서는 국내 축 우선.** 국내 축을 end-to-end로 먼저 완성(P1~P4)하고 해외 축(P3')을 그 뒤에 붙인다. 해외 축이 지연돼도 국내만으로 시연이 성립하는 구조를 유지한다.
2. **해외 화이트리스트는 15개 내외로 시작**한다(명세 제안 20~30개의 하한 밑). 종목당 수집·생성·검수 비용이 있으므로 시연에 실제로 쓸 만큼만. 목록은 팀 확정 필요(테슬라·엔비디아·애플 등 인지도순 권장).

## 5. RAG 지식베이스 — v3에 없지만 유지 (신규 번호 F-5.8)

심사 요구("RAG 사용 시 기술 설명 가능")와 환각 억제를 위해 유지한다. v3 반영으로 소스가 하나 늘었다:

- 소스: ① 한국은행 경제금융용어 700선 ② **국내 공시유형 해설** ③ **미국 폼 유형 해설(F-4.6.1과 동일 데이터)**
- 파이프라인: 청킹 → OpenAI 임베딩 → pgvector 코사인 top-3 (유사도 하한 미달 시 미주입)
- 사용처: 용어 풀이(F-5.4), 국내 공시 요약(F-5.1), 해외 공시 요약(F-5.1)

구현 확정 (2026-08-14, 실측):

| 항목 | 확정 |
| :---- | :---- |
| 700선 원본 | 한국은행 2020년판 PDF → `scripts/parse_bok700.py`(1회성, pypdf)로 파싱 → `data/bok_700.json` **685건**(692 중 98.9%, 목차 대조 방식) |
| 청킹 | 용어 1건 = 청크 1개(정의 200~900자 — 추가 분할 불필요). 임베딩 입력은 `용어명\n정의` |
| 검색 순서 | **① 표제어 정확 일치**(사전 조회 — 'PER'→'주가수익비율(PER)', 임베딩 생략) → ② 벡터 검색 |
| 유사도 하한 | 코사인 **0.45** — 실측에서 미수록 용어에 0.41짜리 무관 근거가 잡혀 0.35에서 상향. 미달 근거는 주입하지 않는다 |
| 벡터 인덱스 | **미사용(전수 스캔)** — 701행 규모에선 1ms 미만·재현율 100%. 수만 청크로 커지면 HNSW 한 줄 전환(RAG설명.md 참조) |
| 국내 공시 해설 주입 | DART `report_nm`을 분류표(12유형, 데이터 관리) **부분 일치·긴 이름 우선**으로 `doc_type` 분류 → 요약 입력에 해설 첨부. 분류 불가 유형은 해설 없이 진행 |

SA 피드백: 커뮤니티·댓글·포인트가 세션 쿠키에 묶여 쿠키 유실 시 데이터 접근 불가. F-1(모의 로그인)을 대체하지 않고 **그 위에 얕은 실계정을 얹는다**.

| 항목 | 확정 | 근거 |
| :---- | :---- | :---- |
| 방식 | **JWT 아님** — httpOnly 세션 쿠키 유지 + `app_user` 테이블 | 동일 출처 프록시(확정사항 4절) + 커뮤니티 서버 상태 구조라 무상태 토큰의 이점이 없고, 헤더 방식 전환은 프론트 전 API 수정 |
| 데이터 연결 | 계정이 **주인 세션**(`primary_session_id`)을 기억. 로그인한 쿠키 세션은 deps에서 주인 세션으로 치환 | 서비스 코드(세션 귀속 72곳) 무변경 — 포인트·베팅·댓글·저장카드·종목이 계정 단위로 복구 |
| 가입 | `POST /auth/signup` — id 4~20자(`[a-z0-9_]`)·pw 8자+·닉네임 1~12자. **가입 시점 쿠키 세션이 주인이 됨(익명 활동 승계)**. 같은 세션이 이미 다른 계정의 주인이면 새 주인 세션 분리(계정 간 데이터 공유 금지) | — |
| 로그인 | `POST /auth/login` — 실패 401(아이디 미존재도 해시 1회로 타이밍 균등), **IP 10회/분** 레이트리밋 | 무차별 대입 방어 |

| 인증 게이트(F-1.3) | `authenticated`(모의) **or** `user_id`(실계정) — mock-login 공존(시연·테스트) | 기존 테스트·시연 흐름 무변경 |
| 주인 세션 만료 | 접근 시마다 30일 연장 | 계정 데이터가 세션 TTL로 죽지 않게 |
| 운영 반영 | `scripts/migrate_auth.py` — `session.user_id` ALTER + `app_user` 생성, 멱등·무손실 | create_all은 기존 테이블에 컬럼 추가 불가 |
| 안 만드는 것 | 이메일 인증·비밀번호 재설정·소셜(추후 `provider` 컬럼으로 확장)·토큰·프로필 수정 | 해커톤 범위 |
