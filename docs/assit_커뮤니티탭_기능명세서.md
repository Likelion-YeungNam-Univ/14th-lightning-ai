# assit 커뮤니티 탭 기능명세서

팀 번개조 | 2026.08 | 기준 문서: `assit 요구사항명세서 v3` · Figma `VOqmXJaJrcKZJSE7IsWQIn`
기능 ID 체계 `[C-n.n.n]` — 기존 `[F-n.n.n]`과 구분

---

## 0. 이 기능이 무엇인가

종목별로 사용자가 **베팅방**을 만들고, 다른 사용자가 `간다 / 안 간다`에 포인트를 걸어 **판가름 날짜에 자동 정산**되는 커뮤니티입니다. 모은 포인트로 **피자 기프티콘**을 교환합니다.

**기존 다섯 출처 탭과 같은 줄, 즐겨찾기 오른쪽에 여섯 번째 탭으로 붙습니다.** 4층 구조(구분 → 종목 줄 → 출처 탭 → 콘텐츠)는 그대로입니다.

**목적은 트래픽입니다.** 자료를 읽는 것만으로는 재방문이 생기지 않아, 논쟁과 판가름 대기가 재방문 이유를 만듭니다.

---

## 1. 착수 전 확정이 필요한 것

| # | 항목 | 왜 막히는가 | 상태 |
| --- | --- | --- | --- |
| ~~C-B1~~ | 결제 PG 선정 | C-8 충전 | **해소** — 토스페이먼츠 **테스트 키** (C-8.2.0) |
| **C-B2** | **기프티콘 조달 경로** | C-9 실물 발급 | **시연 범위에서 제외** — 발급 완료 화면까지만 (C-9.1.5) |
| ~~C-B3~~ | 종가 데이터 소스 | C-6.2 자동 정산의 판정 기준값 | **해소** — FinanceDataReader (C-6.2.0) |
| C-B4 | TradingView 위젯 약관 확인 | 상업적 이용 조건 | 미해소 |

**해커톤 제출물 범위에서는 남은 블로커가 없습니다.** 결제는 테스트 키로, 기프티콘 실물 발급은 범위에서 빼는 것으로 정리했습니다. 실서비스로 넘어갈 때 두 항목을 다시 열어야 합니다.

**실결제를 붙이지 않는 이유** — 라이브 키는 사업자등록이 있어야 발급되고, 실제로 돈을 받으면 통신판매업 신고와 청소년 보호 의무가 따라옵니다. 해커톤 제출물이 감당할 범위가 아닙니다.

## 2. 포인트 규칙 (전 기능 공통)

| 항목 | 값 |
| --- | --- |
| 환산 | **1P = 1원** |
| 충전 상품 | 5,000P / 10,000P / 30,000P |
| 1회 베팅 | 기본 500P, **최대 1,000P** |
| 보유 상한 | **30,000P** |
| 피자 한 판 기프티콘 | **18,000P** |
| 신규 가입 지급 | **없음** |
| 교환 제한 | 계정당 **월 1회** |
| 환불 | 충전·교환 모두 **불가** |

**피자값을 충전액보다 비싸게 잡은 것이 설계 의도입니다.** 18,000P를 현금으로 사면 18,000원인데 피자 원가는 그보다 낮습니다. **현금으로 사면 손해라 아무도 그 경로를 쓰지 않습니다.** 이 관계가 깨지면 차익거래가 생기므로, 피자 포인트가를 원가보다 낮게 조정하지 마세요.

포인트는 **제로섬**입니다. 베팅으로 총량이 늘지 않습니다.

| [C-6.2.5] 결과 통보 | 사용자 확인 | | 정산 후 방 상태를 `closed`로 바꾸고 결과 배지를 붙인다. 알림은 (제안) 범위 밖 | 중 |

# C-12. 비기능

| 항목 | 내용 |
| --- | --- |
| 정산 신뢰성 | 배치 실패 시 재시도 가능해야 한다. 정산 결과는 원장에만 기록하고 잔액을 직접 쓰지 않는다. **정산에 쓴 종가를 `settle_close_price`에 남긴다** — 분쟁 시 판정 근거가 된다 |
| 이상 참여 탐지 | 같은 방에 동일 IP·기기가 여러 계정으로 들어오면 (제안) 참여를 막는다 |
| 개인정보 | 닉네임 외 식별 정보를 커뮤니티에 노출하지 않는다 |
| 결제 로그 | 결제·교환 요청과 응답을 별도 로그로 남긴다. 분쟁 대응에 필요하다 |
| 콘텐츠 | 방 제목·본문·댓글에 매수·매도 권유 표현이 들어와도 **서비스가 생성한 것이 아님**을 화면에 표기한다 |

## 부록. 담합이 무의미한 이유

심사나 검토에서 "여러 계정으로 공모하면 되지 않나"라는 질문이 나올 수 있습니다.

- 포인트는 **제로섬**이라 베팅으로 총량이 늘지 않습니다
- 4계정으로 몰아줘도 결국 **18,000P를 넣고 피자 한 판**을 받습니다
- 18,000P를 현금으로 사면 **18,000원**이고 피자 원가는 그보다 낮습니다

**어떻게 담합해도 손해**입니다. 이 관계는 **피자 포인트가를 원가보다 낮추는 순간 깨지므로**, 가격 조정 시 반드시 재검토해야 합니다.
