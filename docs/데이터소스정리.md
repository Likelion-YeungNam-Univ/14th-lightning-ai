# 데이터 소스 정리 — 지금 가져오는 것 · 더 가져올 수 있는 것

> 백엔드 실측 기준(2026-08-15). 프론트·디자인 참고용.
> 모든 카드는 공통 스키마 하나: `title · summary_short/full · label(+이유) · source_name · published_at · origin_url · details(슬롯) · is_saved` + 탭 전용 필드. 탭마다 어떤 칸이 채워지고 어떤 칸이 null인지가 아래 내용이다.

## 0. 슬롯(details) 규칙 — 디자인 공통

- 슬롯 내용은 백엔드가 **"라벨+값" 완성품**으로 내려준다 → 디자인·프론트가 유형별 내용을 정할 필요 없음
- **개수는 0~4개 가변** — 0개면 슬롯 영역 자체를 숨긴다
- 값 형태는 다양: 큰 숫자("7,174,299,854,900원"), 날짜("2026년 06월 23일"), 짧은 문장("독립이사 보수 지급")
- 긴 금액의 축약 표기("7.2조 원")는 프론트 표기 규칙으로 처리 권장

## 1. 유튜브 탭 (국내·해외 공통)

| 구분 | 내용 |
| --- | --- |
| 지금 가져오는 것 | 제목(원문) · 채널명 · 조회수 · 썸네일 URL · 영상 링크 · 게시일 |
| null인 칸 | 요약·라벨·슬롯 전부(정책상 유튜브는 AI 가공 안 함). 대신 `disclaimer: true` 고지 노출 |
| 더 가져올 수 있는 것 | 좋아요 수·영상 길이(추가 API 1유닛). 자막 텍스트는 쿼터·약관 부담으로 범위 밖 판단 |
| 원천 | YouTube Data API v3 (search 100유닛 + videos 1유닛, 일 10,000 쿼터·80% 가드) |

## 3. 공시 탭 — 해외 (SEC EDGAR)

| 구분 | 내용 |
| --- | --- |
| 지금 가져오는 것 | 폼 4종(8-K·10-Q·10-K·6-K) · 문서 설명(영문 그대로, 미번역) · 제출일 · 원문 링크 · 폼 해설 기반 **한국어** 요약·라벨 |
| 슬롯 | 없음 — SEC엔 공시별 정형 요약 API가 없음 |
| 더 가져올 수 있는 것 | **`companyfacts` API — 매출·순이익 등 재무 수치가 정형(XBRL)으로 옴.** "실적 슬롯"을 만들 수 있는 유일한 후보(확장 1순위 감). 8-K 사안 코드(item)로 "무슨 일인지" 분류도 가능 |
| 원천 | SEC submissions API (User-Agent 필수, 초당 10회 한도) |

## 4. 규제 탭 — 국내(정책브리핑) · 해외(Federal Register)

| 구분 | 내용 |
| --- | --- |
| 지금 가져오는 것 | 제목 원문 · 부처/기관명 · 게시일 · 원문 링크 · **본문/초록**(화면 미노출 — AI 요약 입력 전용) · 업종 연결 · 요약·라벨 |
| 슬롯 | 없음 (정형 수치가 없는 문서형 데이터) |
| 더 가져올 수 있는 것 | 국내: 국가법령정보센터 API(법령·입법예고 — 별도 활용신청 필요), 부처별 RSS(본문이 없어 현 API의 하위 호환 → 불필요 판단). 해외: Federal Register는 이미 전체 필드 활용 중 |
| 원천(국내) | 정책브리핑 정책뉴스 API v2 — 필드: NewsItemId·Title·SubTitle1~3·**DataContents(본문 전체)**·MinisterCode(부처명)·ApproveDate·OriginalUrl·KoglType. 제약: 파라미터 3개(serviceKey·startDate·endDate), **조회 범위 최대 3일** → 90일을 31청크로 수집 |
| 원천(해외) | Federal Register documents API — title·abstract·agencies·publication_date·html_url·document_number·type. RULE·PRORULE만, 기관 필터 필수 |

## 5. 한국은행 탭

| 구분 | 내용 |
| --- | --- |
| 지금 가져오는 것 | 기준금리 수치+변동 방향(`indicator_value` 예 "2.75%"·"인상") · 결정문 카드(제목·요지·링크 — **수동 시드**) · 업종별 "내 종목엔" 문장 |
| 원천 | ECOS StatisticSearch `722Y001/D` + **항목코드 0101000 필터 필수**(없으면 타 시리즈 혼입 — 실측). 필드: STAT_CODE·STAT_NAME·ITEM_CODE1·ITEM_NAME1·UNIT_NAME·TIME·DATA_VALUE |
| 더 가져올 수 있는 것 | **한국은행 보도자료 RSS**(실측 확인: `bok.or.kr/portal/bbs/P0000559/news.rss?menuNo=200690`) — 금통위 결정문·의사록 발행을 자동 감지(title·link·description·pubDate). 요지 본문은 페이지 파싱 필요 → "감지 자동 + 요지 사람 확인" 반자동이 현실적. ECOS 다른 지표(환율·물가·100대 지표 `KeyStatisticList`)도 같은 키로 즉시 추가 가능 |

## 한 줄 요약 + 확장 우선순위

- **슬롯(라벨+값)이 나오는 곳은 국내 공시 정형 6종뿐** — 나머지 탭은 요약 중심 + 탭 전용 필드
- 확장 여지 상위 2개 (원하면 이슈 등록 후 진행):
  1. **BOK·Fed RSS로 금리 결정문 감지 자동화** — 반나절, 수동 시드의 "새 결정 놓칠 위험" 제거
  2. **SEC companyfacts로 해외 실적 슬롯** — 1일+, 해외 공시 카드에 매출·이익 배지 추가
