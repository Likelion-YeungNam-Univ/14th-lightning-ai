# 데이터 소스 정리 — 지금 가져오는 것 · 더 가져올 수 있는 것

> 백엔드 실측 기준(2026-08-15). 프론트·디자인 참고용.
> 모든 카드는 공통 스키마 하나: `title · summary_short/full · label(+이유) · source_name · published_at · origin_url · details(슬롯) · is_saved` + 탭 전용 필드. 탭마다 어떤 칸이 채워지고 어떤 칸이 null인지가 아래 내용이다.

## 0. 슬롯(details) 규칙 — 디자인 공통

- 슬롯 내용은 백엔드가 **"라벨+값" 완성품**으로 내려준다 → 디자인·프론트가 유형별 내용을 정할 필요 없음
- **개수는 0~4개 가변** — 0개면 슬롯 영역 자체를 숨긴다
- 값 형태는 다양: 큰 숫자("7,174,299,854,900원"), 날짜("2026년 06월 23일"), 짧은 문장("독립이사 보수 지급")
- 긴 금액의 축약 표기("7.2조 원")는 프론트 표기 규칙으로 처리 권장

## 1. 유튜브 탭 (국내·해외 공통)

| 구분 | 내용 |
| --- | --- |
| 지금 가져오는 것 | 제목(원문) · 채널명 · 조회수 · 썸네일 URL · 영상 링크 · 게시일 |
| null인 칸 | 요약·라벨·슬롯 전부(정책상 유튜브는 AI 가공 안 함). 대신 `disclaimer: true` 고지 노출 |
| 더 가져올 수 있는 것 | 좋아요 수·영상 길이(추가 API 1유닛). 자막 텍스트는 쿼터·약관 부담으로 범위 밖 판단 |
| 원천 | YouTube Data API v3 (search 100유닛 + videos 1유닛, 일 10,000 쿼터·80% 가드) |

## 2. 공시 탭 — 국내 (DART)

| 구분 | 내용 |
| --- | --- |
| 지금 가져오는 것 | 제목 원문 · 유형 분류(18종) · 게시일 · 원문 링크 · AI 요약·라벨 · **정형 6종 슬롯** |
| 노출 정책 | display=true 12종만 카드 노출(초보자 유용 3 + 정형 6 + 정기보고서 3) — PM 확정 |
| 더 가져올 수 있는 것 | DART 정형 API는 우리가 쓰는 6종 외 **30여 종 더**(전환사채·합병·영업양수도 등) — 같은 구조로 슬롯 확장 가능. 공시 원문 전문 파싱은 범위 밖 확정 |
| 원천 | DART list.json + 유형별 정형 API(피드 매핑: `data/dart_detail_map.json`) |

## 3. 공시 탭 — 해외 (SEC EDGAR)

| 구분 | 내용 |
| --- | --- |
| 지금 가져오는 것 | 폼 4종(8-K·10-Q·10-K·6-K) · 문서 설명(영문 그대로, 미번역) · 제출일 · 원문 링크 · 폼 해설 기반 **한국어** 요약·라벨 |

| 원천 | SEC submissions API (User-Agent 필수, 초당 10회 한도) |

## 한 줄 요약 + 확장 우선순위

- **슬롯(라벨+값)이 나오는 곳은 국내 공시 정형 6종뿐** — 나머지 탭은 요약 중심 + 탭 전용 필드
- 확장 여지 상위 2개 (원하면 이슈 등록 후 진행):
  1. **BOK·Fed RSS로 금리 결정문 감지 자동화** — 반나절, 수동 시드의 "새 결정 놓칠 위험" 제거
  2. **SEC companyfacts로 해외 실적 슬롯** — 1일+, 해외 공시 카드에 매출·이익 배지 추가

## 7. 연결 축 — 가져온 자료를 어느 종목에 붙이나 (리뷰 반영 추가)

각 원천 API는 "이 자료가 어느 종목 것인지"를 모른다. 그걸 이어주는 축이 아래 3개다.

### 7-1. 종목 마스터 (종목코드·이름·업종·시가총액의 출처)

| 구분 | 출처 | 내용 |
| --- | --- | --- |
| 국내 | **KRX** (FinanceDataReader `KRX`+`KRX-DESC` 병합) | 종목코드·종목명·시장(KOSPI/KOSDAQ)·업종 문자열·**시가총액(직접 제공)**. 매일 06:00 갱신. 기본 제공 4종목 = 시총 상위 보통주(우선주는 코드 끝자리로 제외) |
| 해외 | `data/overseas_whitelist.json` (**15종 확정**) | 수기는 티커·한글명·별칭뿐 — **CIK·SIC는 SEC에서 스크립트가 실시간 해석**(수기 아님). 시가총액은 안 받음(화이트리스트라 기본 종목 산출에 불필요 — 확정사항) |

확정 화이트리스트 15종: TSLA·AAPL·NVDA·MSFT·GOOGL·AMZN·META·NFLX·AVGO·AMD·INTC·LLY·KO·SBUX·JPM

### 7-2. 업종 분류 체계 (규제 매칭과 "내 종목엔" 문장의 공통 축)

- 국내: **자체 12분류** (반도체·자동차/이차전지·화학/정유·조선/방산·철강/소재·유통/식품·건설·금융·바이오·플랫폼/게임·통신·미디어 + 기타). KRX 업종 문자열을 `data/industry_rules.json` 키워드 규칙(순서 매칭)으로 변환해 종목마다 부여
- 해외: **SIC 코드**(미국 표준 업종 코드)를 그대로 업종 키로 사용 — 화이트리스트가 걸치는 11종 커버
- 이 축 하나가 세 가지를 동시에 결정: ① 업종→소관 부처/기관 매핑(규제 수집 범위) ② 업종 키워드(규제 2차 필터) ③ 업종 성격 서술(profile — "내 종목엔" 문장 입력). 전부 `data/*.json`으로 관리 — 코드 수정 없이 조정 가능

### 7-3. 종목 → 소스 매칭 방식 (탭별)

| 탭 | 매칭 키 | 방식 |
| --- | --- | --- |
| 국내 공시 | 종목코드 → **corp_code** | DART corpCode.xml 전체 매핑(약 2,600종목), 주 1회 갱신 |
| 해외 공시 | 티커 → **CIK**(10자리) | SEC company_tickers.json, 화이트리스트 동기화 시 해석 |
| 규제(국내·해외) | 종목 → **업종**(12분류/SIC) → 자료 | 자료는 업종에 붙고, 종목은 자기 업종의 자료를 본다 |
| 유튜브 | **검색어 규칙** | 국내 `"{종목명} 주식"` / 해외 `"{한글 별칭} 주식"` + 최근 90일 + 조회수순 상위 10. "주식"을 붙여 그룹사·일상 영상 혼입을 줄인다. 특정 종목에서 혼입이 관찰되면 별칭 데이터만 고쳐 검색어 조정 가능 |
| 금리(한국은행·Fed) | 종목 무관(탭 공통) | 카드가 전 종목 공통, **"내 종목엔" 문장만 업종별**로 붙는다 |

### 7-4. 수동 유지 항목 (사람이 채우는 것)

| 항목 | 상태 |
| --- | --- |
| 금통위 결정문·FOMC 성명 | `data/rate_decisions.json` 수동 시드 — **시연 전 최신 회차 확인은 시연체크리스트 D-1 항목에 포함돼 있음.** BOK·Fed RSS 자동 감지(6절 확장 후보 1)를 도입하면 놓칠 위험 제거 |
| 해외 화이트리스트 | **15종 확정·적재 완료** — 수기는 티커·이름·별칭뿐, CIK·SIC는 자동 해석 |
